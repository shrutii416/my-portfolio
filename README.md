# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my introduction, education, technical skills, projects, and contact information in a clean and responsive design.

## 👩‍💻 About Me

Hi, I'm **Shruti Gaikwad**, a Computer Science Engineering student passionate about technology, programming, and web development.

I enjoy learning new technologies and building creative projects to improve my technical skills.

## ✨ Features

- Attractive and modern user interface
- Responsive design for different screen sizes
- Home and About Me sections
- Education details
- Technical Skills showcase
- Projects section
- Resume download option
- Contact section with active social links
- Smooth navigation between sections

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactive functionality
- **Font Awesome** – Icons
- **Google Fonts** – Typography

## 🚀 How to Run the Project

1. Clone this repository:

   `git clone https://github.com/shrutii416/my-portfolio.git`

2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. You can also use the Live Server extension.
